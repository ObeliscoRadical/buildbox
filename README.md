# Buildbox ⚡

> **World's first truly agentic Vibe Coding platform.**  
> Transform natural language ideas into production-ready web and mobile applications in minutes.

---

## 🚀 Features

- **Conversational Multi-Agent Loop:**
  - `Planner / Architect`: Evaluates user intent, schemas, and system design.
  - `Coder`: Generates modular, type-safe Next.js 15, TypeScript, and Tailwind CSS code.
  - `Auto-Healer`: Validates compilation, checks TypeScript types, and repairs errors autonomously.
- **Interactive Studio IDE (`/studio/[id]`):**
  - Live split views: **Preview**, **Code** (Monaco Editor), and **Split**.
  - Multi-device viewport toggling (**Desktop 100%**, **Tablet 768px**, **Mobile 375px**).
  - Collapsible **Terminal & Logs** drawer (Console, Build Output, Agent Trace).
  - One-click source code export as `.zip` archive.
  - One-click deployment with instant subdomains and SSL.
  - Checkpoint version history and instant rollback.
- **Credit-Based Monetization & Account Model:**
  - Starter, Pro, and custom Top-up credit packages.
  - **Zero-Waste Guarantee:** Automatic refunds for failed unhealed turns.
- **Full Application Dashboard (`/dashboard`):**
  - Natural language prompt hero bar with AI model selection (Gemini 2.5 Flash, Gemini 2.5 Pro, Claude 3.7 Sonnet).
  - Project cards management with visual previews, status tracking, and export options.
  - Real-time global apps created ticker.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS & Lucide Icons
- **Code Editor:** `@monaco-editor/react`
- **ZIP Export:** `jszip`

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/DiegoAlvesOliveira/buildbox.git
cd buildbox
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001`) in your browser.
